# План исправления ошибок компиляции DrvAnemon

## Обнаруженные ошибки:

### 1. Ошибки доступа к логированию (CS0122)
- `DeviceLogic.Log` недоступен
- В AnemonAvtoProtocol.cs используется неправильный способ доступа к логированию

### 2. Ошибки конфигурации линии связи (CS1061)
- `LineConfig.Port` не существует
- Нужно найти правильный способ получения порта TCP сервера

### 3. Ошибки статусов устройства (CS1503, CS1061)
- `DeviceStatus.Off` не существует
- Нужно использовать правильные статусы из Rapid SCADA

### 4. Ошибки типов данных (CS1503)
- `DeviceData.Set(2, DateTime.UtcNow)` - нельзя передавать DateTime в double
- `DeviceData.Set(tagIndex, value)` для строковых значений

### 5. Ошибки области видимости переменных (CS0103)
- Переменная `deviceLogic` не существует в некоторых методах

## План исправления:

### Шаг 1: Исправление логирования
- Заменить `deviceLogic?.Log?.WriteLine()` на правильный способ логирования
- Добавить параметр логгера в методы протокола

### Шаг 2: Исправление конфигурации
- Найти правильный способ получения порта TCP сервера
- Использовать существующие API Rapid SCADA

### Шаг 3: Исправление статусов
- Использовать правильные статусы устройства из Rapid SCADA
- Найти правильные константы статусов

### Шаг 4: Исправление типов данных
- Использовать правильные методы для разных типов данных
- Для DateTime использовать Unix timestamp или другие подходящие методы

### Шаг 5: Исправление области видимости
- Передать все необходимые параметры в методы
- Исправить область видимости переменных

## Стратегия:
1. Изучить существующие примеры в проекте
2. Найти правильные API Rapid SCADA
3. Исправить ошибки пошагово
4. Протестировать компиляцию после каждого исправления

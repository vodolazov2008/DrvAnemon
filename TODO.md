## Технические детали протокола ANEMON-AVTO

### Основные характеристики:
- Транспорт: TCP
- Порт: 4004
- Формат: JSON
- Архитектура: запрос-ответ

### Типы сообщений:
1. **Request Type 1** - Идентификация устройства
2. **Time Sync** - Синхронизация времени (сервер → клиент)
3. **Request Type 2** - Отправка данных с датчиков
4. **Response Type 2** - Подтверждение получения (сервер → клиент)

### Особенности:
- Фрагментация TCP пакетов для больших сообщений
- Завершающий символ `~` в сообщениях
- Временная синхронизация
- Поддержка до 256 датчиков

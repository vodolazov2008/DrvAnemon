# План реализации HTTP протокола версии 3 для DrvAnemon

## Анализ задачи
- Полная замена существующих протоколов 1-2 на HTTP/JSON протокол версии 3
- Драйвер должен содержать встроенный HTTP сервер для приема POST запросов от устройств
- Поддержка команды "get_last_ts" с JSON запросами/ответами
- Структура дальнейших команд неизвестна

## План реализации

### 1. Создание HTTP сервера
- **HttpServer.cs**: Встроенный HTTP сервер для приема POST запросов
- **HttpRequestHandler.cs**: Обработчик HTTP запросов с JSON парсингом
- Поддержка заголовков: Anemon-Protocol, Anemon-Token, Content-Length, Content-Type
- Парсинг JSON команды "get_last_ts"

### 2. Создание JSON протокола
- **ProtocolV3.cs**: Класс для работы с HTTP/JSON протоколом
- Парсинг входящих JSON команд {"cmd":"get_last_ts","data":[{"serial":"...","save_interval":...}]}
- Формирование JSON ответов {"cmd":"get_last_ts_resp","ts":...,"data":[...]}
- Валидация токенов и серийных номеров

### 3. Обновление логики устройства
- **DevAnemonLogic.cs**: Полная замена протоколов 1-2 на HTTP протокол
- Интеграция HTTP сервера в драйвер
- Обработка команды "get_last_ts": получение последних временных меток для устройств
- Управление данными устройств и формирование ответов

### 4. Обновление конфигурации
- **DriverUtils.cs**: Обновление констант и утилит
- Удаление старых констант протоколов 1-2
- Добавление констант для HTTP протокола версии 3

### 5. Обновление основной логики
- **DrvAnemonLogic.cs**: Обновление фабрики устройств для HTTP протокола
- Удаление поддержки старых протоколов

### 6. Удаление старого кода
- Удаление класса Protocol.cs (старые протоколы 1-2)
- Удаление методов DecodeDataPacket и связанной логики
- Очистка TagIndex.cs от неиспользуемых констант

## Технические детали

### HTTP сервер
- Использование HttpListener для встроенного HTTP сервера
- Обработка POST запросов на указанном порту
- Асинхронная обработка запросов

### JSON парсинг
- Использование System.Text.Json для работы с JSON
- Структуры данных для команд и ответов
- Валидация форматов данных

### Конфигурация
- Настройка порта HTTP сервера
- Токены для авторизации устройств
- Соответствие серийных номеров устройствам в системе

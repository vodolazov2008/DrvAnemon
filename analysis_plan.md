# План анализа проекта DrvAnemon

## Собранная информация:

### Общая структура проекта
- **DrvAnemon.Logic** - основная логическая часть драйвера для RapidScada
- **DrvAnemon.View** - пользовательский интерфейс для конфигурации драйвера
- Это декомпилированный C# проект из RapidScada SCADA системы

### Основные компоненты:

**DrvAnemon.Logic:**
- `DrvAnemonLogic.cs` - главный класс драйвера, наследуется от DriverLogic
- `DevAnemonLogic.cs` - логика работы с конкретным устройством, наследуется от DeviceLogic
- `Protocol.cs` - парсинг и обработка протокола обмена данными
- `TagIndex.cs` - индексы тегов (PacketReceived, PacketFailed, DateTime, Sensors)
- `CnlPrototypeFactory.cs` - фабрика прототипов каналов (256 сенсоров)
- `DriverUtils.cs` - утилиты драйвера

**DrvAnemon.View:**
- `DrvAnemonView.cs` - главный класс представления драйвера
- `DevAnemonView.cs` - представление конкретного устройства
- `CnlPrototypeFactory.cs` - фабрика прототипов каналов

### Функциональность:
1. **Прием данных от контроллеров Анемон** через TCP-сервер в режиме Slave
2. **Протокол передачи данных** в формате: `#id:device_id;datetime:yyyyMMddHHmmss;live:1;t1:value1;t2:value2#`
3. **Обработка данных** с поддержкой до 256 сенсоров
4. **Система тегов и каналов** для мониторинга связи и получения данных
5. **Интеграция в RapidScada** через стандартные интерфейсы DriverLogic/DeviceLogic

### Технические детали:
- **Framework**: .NET 6.0+
- **Namespace**: Scada.Comm.Drivers.DrvAnemon
- **Протокол**: текстовый, ASCII
- **Транспорт**: TCP
- **Поведение**: Slave (пассивный прием данных)
- **Версии протокола**: 1 и 2 (с поддержкой временных меток в ACK)
